## Own review of main..524b6d1

Range: the 15 commits from cb836f4 to 524b6d1, including the `.codex` and
`.github` changes the OpenAI request leaves out. No findings that need a code
change.

- Visibility: every entry is core's `issues/show.api.rsb` rendered as the
  exporting user, with the instance variables `IssuesController#show` sets
  (`visible_journals_with_index`, visible relations, visible changesets, spent
  time only with `view_time_entries`). Private notes, journal details of hidden
  fields, custom field visibility and watchers follow core's view. The examples
  compare each entry with `GET /issues/:id.json` for the same user.
- Permissions: `export_issues_json` on the project of every visible issue
  (`allowed_to?` with an array, which also checks the issue tracking module and
  archived or closed projects), `issues#show` per issue, and
  redmine_view_issue_description's `detail_access_granted?`. Invisible or
  missing ids go to `skipped`; the contract spec fails when another
  before_action appears on `IssuesController#show`.
- CSRF and GET: the action changes nothing, so a GET without a token is
  correct. Cross-site reading is not possible: no CORS, JSONP parameters are
  removed before the builder reads them, `application/json` with Rails'
  `nosniff`, `Content-Disposition: attachment`, `Cache-Control: no-store`.
  An API key does not log in (no `accept_api_auth`, route `:format => false`).
- back_url: only used through `redirect_back_or_default`, which applies core's
  `validate_back_url`.
- Input bounds: ids are filtered to 1..2147483647 decimal strings and
  de-duplicated before the limit check; the limit is clamped to 1..200 and
  checked before anything is loaded; non-string ids (hashes, arrays) are
  dropped.
- Logging: `IssueUpdater#log_failure` no longer logs any error message, only the
  class and backtrace.
- Conventions: settings with `DEFAULT_SETTINGS` fallbacks, two locale keys
  added to every shipped locale, core strings reused, COMPATIBILITY.md and
  DECISIONS.md updated, no migration.
- `.codex` and CI: `cma_as_root`/`cma_as_postgres` covered by test_scripts.sh,
  Ruby 4.0 detection for Redmine 7.0, runners pinned, action pins bumped.
